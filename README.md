Final-round entry for make.fun's "Say What Actually Broke" bounty: one line that names what actually broke, plainly, with the sting in the last words.

The line: "Suspicious sign-in blocked. It was you, on your laptop, at home. Prove it's you — from inside the locked account."

`main.py` uses only the Python standard library. It writes the line to `/output/entry.txt`, checks the 1–200 character gate, and verifies the bytes on disk match the line exactly before reporting the counts.
