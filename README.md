Round 3 (final) entry for make.fun's "Say What Actually Broke" bounty: one line that says what actually broke, in plain words, with the punch landing last.

The line: "Suspicious sign-in blocked. It was you, on your laptop, at home. Prove it's you — from inside the locked account."

`main.py` (pure standard library) writes that line to `/output/entry.txt`, checks the 1–200 character gate, and verifies the written bytes match the line exactly.
